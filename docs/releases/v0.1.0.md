# knapper v0.1.0

The first packaged release of knapper: a headless CLI that works directly on Markdown and Org knowledge bases.

## Highlights

- Inspect links, backlinks, tags, metadata, tasks and note context without running a note-taking app or indexing service.
- Move and rename notes with link-preserving edits and dry-run previews.
- Configure lint rules by path and metadata, including required headings and frontmatter. Check selected files or Git changes.
- `broken-links` now respects lint policies by default. Use `--all` for diagnostic inspection outside those policies.
- Create daily notes and manage tasks through a strictly validated `knapper.yaml` configuration.
- Install one binary on macOS or Linux, with the agent skill embedded in the executable.
- Verify release provenance during `self-update`, using the same attestation verification and embedded-installer approach as dlgt. Interactive commands check for updates in the background at most every six hours and notify without changing stdout.

## Install and update

```sh
curl -fsSL https://raw.githubusercontent.com/combinatrix-ai/knapper/v0.1.0/install.sh | sh
knapper self-update --check
knapper self-update
```

For existing development binaries already reporting `0.1.0`, reinstall through the published installer to obtain this release. Once running the release binary, `self-update --force --yes` can verify and reinstall the same version.

Archives are available for macOS arm64/x86_64 and Linux arm64/x86_64 (musl). Each archive and the checksum manifest have GitHub Actions provenance attestations and downloadable Sigstore bundles. Chrome extension and Native Messaging features are excluded from this release; Windows binaries are not provided.

Automatic checks only notify. Set `KNAPPER_NO_UPDATE_CHECK=1` to disable them. Use `--no-skill` during self-update or `--skill none` during installation if agent skills are managed separately.

This is the first public release, so updating from a previous public release cannot yet be exercised. Same-version verified reinstall is supported; the first version-to-version update must be checked with the next release.
